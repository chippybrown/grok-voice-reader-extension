# Grok Voice Reader

[![Download](https://img.shields.io/badge/Download-brightgreen?style=for-the-badge)](https://github.com/chippybrown/grok-voice-reader-extension/releases/latest/download/Grok-Voice-Reader-Extension.zip)

This add-on reads a new Grok reply out loud. It works in Chrome, Edge, and Brave.

## Install

1. Click the green **Download** button. Unzip the file. On Windows, right-click the zip and choose **Extract All**. On a Mac, double-click the zip. Put the folder somewhere you will keep, such as Documents. The folder must contain a file named `manifest.json`.

2. Open the extensions page. Type one of these in the address bar and press Enter:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`

3. Turn on **Developer mode**. Click **Load unpacked**. Pick the folder you unzipped.

Leave that folder where it is. The browser loads the add-on from that place. If you move or delete the folder, it stops working. After you load it, refresh the Grok tab, then click the page once.
